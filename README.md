# 로마이야기 (Rome Stories)

어려운 로마 역사를 짧은 한국어로 정리한 정적 사이트입니다. 한 줄 요약과 핵심 세 가지를 먼저 읽고, 더 알고 싶을 때만 「조금만 더」를 엽니다. 전설, 전통 기록, 역사를 구분하고, 고전 출처를 짧게 적습니다.

나두 — 나의 모든 일상을 AI와 함께

자매 사이트 [나두신화](https://nadoo-myth.vercel.app)는 그리스·로마 신화를 다룹니다. 이 사이트의 신화 메뉴는 그쪽으로 이어집니다.

## 메뉴

- **홈** `/` — 시대 개관과 전체 메뉴
- **로마의 탄생·시대** `/origins` — 로물루스 전설과 역사적 성장, 왕정 → 공화정 → 제정
- **지도·지역** `/map` — 이탈리아에서 지중해로. 도시·속주 카드
- **왕·황제** `/rulers`, `/rulers/[slug]` — 일곱 왕, 카이사르, 주요 황제
- **클레오파트라와 로마** `/cleopatra` — 카이사르, 안토니우스, 이집트
- **전쟁** `/wars`, `/wars/[slug]` — 포에니 전쟁, 그리스·마케도니아, 갈리아, 내전, 악티움, 게르만족
- **일상** `/daily` — 밥, 집, 목욕, 포룸, 사람과 법
- **군인** `/army` — 군단, 장비, 진영, 시민권
- **신과 전설 연결** `/myth-links` — 로마 신과 그리스 신 짝, 나두신화 링크
- **출처** `/sources` — 짧은 서지

## 실행

```bash
npm ci
npm run dev
npm run build
```

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript. `npm run build`는 `out/`에 정적 파일을 만듭니다. 모든 페이지는 빌드 때 생성됩니다.

정식 주소는 `NEXT_PUBLIC_SITE_URL`로 바꿉니다. 기본값은 `https://rome-stories.vercel.app` 입니다.

본문은 `data/`에 있습니다. 어려운 말에는 괄호 풀이를 붙였고, 인용문은 만들지 않습니다.
