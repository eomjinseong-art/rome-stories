# 로마이야기 (Rome Stories)

로마 역사가 어렵게 느껴지는 어른을 위해, 한국어로 짧게 정리한 정적 사이트입니다. 영어 제목은 짧게 두고, 설명은 한국어로 씁니다.

나두 — 나의 모든 일상을 AI와 함께

나두 역사·신화로 이어지는 자매 사이트는 [나두신화](https://nadoo-myth.vercel.app), [그리스이야기](https://greece-stories.vercel.app), [이집트이야기](https://egypt-stories.vercel.app)입니다. 로마이야기는 로마의 정치, 전쟁, 하루를 다룹니다.

## 메뉴

- **홈** `/` — 세 시대와 모든 갈래
- **로마의 탄생·시대** `/origins` — 건국 전설과 마을, 왕정 → 공화정 → 제정
- **지도·지역** `/map` — 이탈리아에서 지중해와 변경까지
- **왕·황제** `/rulers`, `/rulers/[slug]` — 전승 속 왕 7명과 길을 잡는 황제 10명
- **클레오파트라와 로마** `/cleopatra` — 카이사르, 안토니우스, 이집트 정치
- **전쟁** `/wars`, `/wars/[slug]` — 큰 전쟁 8개. 원인·상대·결과
- **일상** `/daily` — 밥, 집, 목욕, 포룸, 사람의 자리
- **군인** `/army` — 군단, 장비, 진영
- **신과 전설 연결** `/myth-links` — 로마·그리스 신 짝, 나두신화로 이어지는 링크
- **관련 영화** `/movies` — 극영화와 시리즈. 어디가 창작인지 구분. 불법 영상 링크 없음
- **출처** `/sources`

글의 꼴은 한 줄 요약, 핵심 세 가지, 펼치는 「조금만 더」입니다. 전설과 역사는 배지로 나눕니다.

## 개발

```bash
npm ci
npm run dev
npm run build
```

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript. 페이지는 빌드 때 정적으로 생성됩니다.

콘텐츠는 `data/`에 있습니다. `NEXT_PUBLIC_SITE_URL`의 기본값은 `https://rome-stories.vercel.app`입니다.

## 적는 기준

고대 기록의 이름과 위치만 밝히고, 없는 인용문을 만들지 않습니다. 현대 책의 문장을 번역해 붙이지 않습니다. 영화 제목은 실제 개봉 제목을 쓰고, 작품을 볼 수 있는 불법 사이트는 안내하지 않습니다.
